# Overview

Trace, evaluate, and improve AI agents with tested guidance.

## What is PandaProbe?

PandaProbe is an open-source agent engineering platform. Capture what your agents do, measure their behavior, and turn evaluated failures into guidance they can use in later executions.

The product stack is **Trace → Evaluate → Reflect**. Use each capability independently or connect them into a feedback loop.

## Start with your existing agent

The Python and TypeScript SDKs support provider wrappers, framework integrations, and manual instrumentation. Keep your model, prompts, business tools, and execution environment.

Reflect adds one isolated filesystem tool to supported agents. The same agent can retrieve guidance, maintain working memory, and reflect at bounded checkpoints. Your verifier supplies outcome evidence, and the SDK applies the validation policy before publishing a change. Generating a plausible reflection alone is not proof of improvement.

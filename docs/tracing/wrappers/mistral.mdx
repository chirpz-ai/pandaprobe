## Chat API

Span name: `"mistral-chat"`, SpanKind: `LLM`

```python title="Python"
response = client.chat.complete(
    model="mistral-small-latest",
    messages=[
        {"role": "system", "content": "You are a concise assistant."},
        {"role": "user", "content": "Explain recursion in one sentence."},
    ],
    temperature=0.5,
    max_tokens=200,
)
```

```ts title="TypeScript"
const response = await client.chat.complete({
  model: "mistral-small-latest",
  messages: [
    { role: "system", content: "You are a concise assistant." },
    { role: "user", content: "Explain recursion in one sentence." },
  ],
  temperature: 0.5,
  maxTokens: 200,
});
```

**What gets traced**

- Input: `messages` list, captured directly (Mistral already speaks the universal schema)
- Output: assistant message from `choices[0].message`
- Model name (from the response body)
- Token usage
- Model parameters: `temperature`, `top_p`, `max_tokens`, `random_seed`, `safe_prompt`, `response_format`, `tool_choice`, `presence_penalty`, `frequency_penalty`, `n`, `stop`

### Streaming

```python title="Python"
res = client.chat.stream(
    model="mistral-small-latest",
    messages=[{"role": "user", "content": "Hello!"}],
)
with res as event_stream:
    for event in event_stream:
        delta = event.data.choices[0].delta
        if delta.content:
            print(delta.content, end="")
```

The TypeScript wrapper instruments the JavaScript SDK's asynchronous `chat.stream` method:

```ts title="TypeScript"
const stream = await client.chat.stream({
  model: "mistral-small-latest",
  messages: [{ role: "user", content: "Hello!" }],
});
for await (const event of stream) {
  const content = event.data?.choices?.[0]?.delta?.content;
  if (typeof content === "string") process.stdout.write(content);
}
```

Python's `chat.stream` and `chat.stream_async`, plus TypeScript's `chat.stream`, are traced with time-to-first-token and reduced output.

## Token usage mapping

Mistral already uses our canonical names, so the mapping is the identity:

| Mistral Field | PandaProbe Field |
| --- | --- |
| `prompt_tokens` | `prompt_tokens` |
| `completion_tokens` | `completion_tokens` |

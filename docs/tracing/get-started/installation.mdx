### Prerequisites

- Python 3.10 or later for the Python SDK, or Node.js 18 or later for the TypeScript SDK
- A PandaProbe account with an API key

<Note>
  Some optional provider and framework packages require a newer Node.js version. Follow the engine requirements of the integrations you install.
</Note>

### Install the SDK

<Tabs>
  <Tab title="pip">
    ```bash
    pip install pandaprobe
    ```
  </Tab>
  <Tab title="uv">
    ```bash
    uv add pandaprobe
    ```
  </Tab>
  <Tab title="npm">
    ```bash
    npm install pandaprobe
    ```
  </Tab>
  <Tab title="yarn">
    ```bash
    yarn add pandaprobe
    ```
  </Tab>
  <Tab title="pnpm">
    ```bash
    pnpm add pandaprobe
    ```
  </Tab>
</Tabs>

### Install provider and framework dependencies

PandaProbe keeps provider and framework SDKs optional. Install only the packages used by your application.

<Tabs>
  <Tab title="Python">
    | Integration | Install command |
    | --- | --- |
    | OpenAI | `pip install "pandaprobe[openai]"` |
    | Anthropic | `pip install "pandaprobe[anthropic]"` |
    | Gemini | `pip install "pandaprobe[gemini]"` |
    | Mistral | `pip install "pandaprobe[mistral]"` |
    | LiteLLM | `pip install "pandaprobe[litellm]"` |
    | AWS Bedrock | `pip install "pandaprobe[bedrock]"` |
    | LangGraph | `pip install "pandaprobe[langgraph]"` |
    | LangChain | `pip install "pandaprobe[langchain]"` |
    | DeepAgents | `pip install "pandaprobe[deepagents]"` |
    | Google ADK | `pip install "pandaprobe[google-adk]"` |
    | Claude Agent SDK | `pip install "pandaprobe[claude-agent-sdk]"` |
    | CrewAI | `pip install "pandaprobe[crewai]"` |
    | OpenAI Agents SDK | `pip install "pandaprobe[openai-agents]"` |

    With uv, replace `pip install` with `uv add`. You can combine extras, for example `uv add "pandaprobe[openai,anthropic,gemini]"`.
  </Tab>
  <Tab title="TypeScript">
    | Integration | Additional packages |
    | --- | --- |
    | OpenAI | `openai` |
    | Anthropic | `@anthropic-ai/sdk` |
    | Gemini | `@google/genai` |
    | Mistral | `@mistralai/mistralai` |
    | AWS Bedrock | `@aws-sdk/client-bedrock-runtime` |
    | LangGraph | `@langchain/langgraph @langchain/openai @langchain/core` |

    ```bash
    # or: yarn add pandaprobe openai
    # or: pnpm add pandaprobe openai
    ```
  </Tab>
</Tabs>

<Note>
  LiteLLM, CrewAI, and Google ADK integrations are currently Python-only. Vercel AI SDK integration is TypeScript-only.
</Note>

### Configure environment variables

Minimum required setup for both SDKs:

```bash
export PANDAPROBE_API_KEY="your-api-key"
export PANDAPROBE_PROJECT_NAME="my-project"
```

<Tip>
  You can also configure the SDK programmatically with Python's `pandaprobe.init(...)` or TypeScript's `init({...})`. See [Project Configuration](/tracing/configuration/project-configuration).
</Tip>

For the full list of variables, see [Environment Variables](/tracing/configuration/environment-variables).

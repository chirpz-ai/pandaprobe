**Agent framework integrations** hook into framework callbacks, processors, or middleware to trace agent lifecycles and model operations: LLM calls, tool invocations, sub-agent handoffs, guardrails, and related steps.

Use the table below to choose a supported SDK, then open the integration guide for framework-specific setup.

| Integration | Python | TypeScript | Instrumentation |
| --- | --- | --- | --- |
| LangGraph | `LangGraphCallbackHandler` | `LangGraphCallbackHandler` | Framework callback handler |
| LangChain | `LangChainCallbackHandler` | `LangChainCallbackHandler` | Framework callback handler |
| DeepAgents | `DeepAgentsCallbackHandler` | `DeepAgentsCallbackHandler` | Framework callback handler |
| Google ADK | `GoogleADKAdapter` | — | Runtime instrumentation |
| Claude Agent SDK | `ClaudeAgentSDKAdapter` | `wrapClaudeAgentQuery` | Adapter / query wrapper |
| CrewAI | `CrewAIAdapter` | — | Runtime instrumentation |
| OpenAI Agents SDK | `OpenAIAgentsAdapter` | `OpenAIAgentsAdapter` | Tracing processor |
| Vercel AI SDK | — | `pandaProbeMiddleware` | Language model middleware |

Shared options are `session_id`, `user_id`, `tags`, and `metadata` in Python, and `sessionId`, `userId`, `tags`, and `metadata` in TypeScript. Vercel middleware currently accepts an optional span `name`; use the TypeScript `session()` and `user()` scopes for attribution.

<Note>
  All integrations automatically produce properly nested span hierarchies. You do not need to create traces or spans manually.
</Note>

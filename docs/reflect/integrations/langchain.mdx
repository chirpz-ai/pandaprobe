Use Reflect with LangChain’s native agent factory. Reflect attaches its filesystem tool and memory context; the existing PandaProbe callback records agent, model, and tool execution.

## Enable Reflect

This example creates a policy assistant. Add your own domain tools where indicated; Reflect supplies `reflect_bash` automatically.

<CodeGroup>
```python title="Python"
import asyncio

from langchain.agents import create_agent
from langchain_openai import ChatOpenAI
from langgraph.checkpoint.memory import InMemorySaver
from pandaprobe.integrations.langchain import LangChainCallbackHandler
from pandaprobe import Client
from pandaprobe.reflect import Reflect


async def main():
    client = Client()
    try:
        async with Reflect(client) as reflect:
            agent = reflect.agent(
                create_agent,
                model=ChatOpenAI(model="gpt-6-luna", reasoning_effort="none"),
                system_prompt="For standard returns, refund merchandise paid and exclude outbound shipping. Explain the policy clearly.",
                tools=[],  # Your native business tools go here.
                checkpointer=InMemorySaver(),
            )
            result = await reflect.run(
                agent, "I paid $65 for an item and $7 for shipping. What is refundable?", session_id="customer-42",
                config={"callbacks": [LangChainCallbackHandler(client=client)]},
            )
            print(result["messages"][-1].content)
    finally:
        client.shutdown()


asyncio.run(main())
```

```ts title="TypeScript"
import { createAgent } from "langchain";
import { ChatOpenAI } from "@langchain/openai";
import { MemorySaver } from "@langchain/langgraph";
import { LangChainCallbackHandler } from "pandaprobe/integrations/langchain";
import { Client } from "pandaprobe";
import { Reflect as ReflectRuntime } from "pandaprobe/reflect";

async function main() {
  const client = new Client();
  const reflect = new ReflectRuntime(client);
  try {
    const agent = await reflect.agent(createAgent, {
      framework: "langchain",
      options: {
        model: new ChatOpenAI({ model: "gpt-6-luna", reasoning: { effort: "none" } }),
        systemPrompt: "For standard returns, refund merchandise paid and exclude outbound shipping. Explain the policy clearly.",
        tools: [], // Your native business tools go here.
        checkpointer: new MemorySaver(),
      },
      invokeOptions: { callbacks: [new LangChainCallbackHandler({ client })] },
    });
    const result = await reflect.run(agent, "I paid $65 for an item and $7 for shipping. What is refundable?", { sessionId: "customer-42" });
    console.log(result.messages.at(-1)?.content);
  } finally {
    await reflect.close();
    await client.shutdown();
  }
}

main().catch(error => { console.error(error); process.exitCode = 1; });
```
</CodeGroup>

## How the integration behaves

Reflect adds native model/tool middleware while preserving your existing middleware and callbacks. During reflection, business tools are removed from the model’s tool set and blocked by the dispatcher.

### Conversations and replay

The checkpointer keeps native conversation history. Use the same `session_id` / `sessionId` for related turns and a new one for a new conversation. Reflect assigns a fresh execution ID per call unless you supply one.

Reflection continues checkpoint-owned history with new feedback; do not append the previous result yourself. Validation uses a fresh thread and local memory, while your replay callback resets business state.

Tracing uses the [LangChain callback](/tracing/integrations/langchain) attached to the same client. Keep that callback on replay invocations as well.

`run()` returns the task's native result after evaluation and any triggered reflection. A healthy answer may produce no proposal. The workspace persists accepted guidance and pending proposals across restarts.

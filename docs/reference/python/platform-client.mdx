---
title: "Platform client"
description: "Read persisted traces and create or poll evaluation runs"
---

This asynchronous HTTP client reads persisted evidence and starts or polls trace evaluations independently of trace export. It reuses an existing tracing client's resolved endpoint, API key, and project, with a separate lifecycle. Close it separately when you supply it to Reflect.

The SDK currently exposes trace reads and trace evaluation resources. The [HTTP API](/reference/api/introduction) also documents operations such as sessions and monitors that are not typed SDK resources here.

All timeouts and polling intervals are **seconds**. Safe GETs have bounded retries; evaluation creation is sent once because the server has no idempotency-key contract. Poll the returned run ID. An uncertain create outcome must not be automatically retried.

`wait_visible` / `waitVisible` waits for a terminal persisted trace, including an error trace. Evaluation `wait` requires usable scores for every requested trace/metric pair; terminal status alone is insufficient. Missing, duplicate, nonnumeric, or failed evidence does not become a passing result.

## Example

This creates a real evaluation run for an existing trace. `trace_id` is a persisted task trace UUID from the same project.

```python
from pandaprobe import Client
from pandaprobe.api import PlatformClient


async def evaluate(trace_id: str):
    client = Client()
    try:
        async with PlatformClient(client) as api:
            await api.traces.wait_visible(trace_id)
            run = await api.evaluations.create([trace_id], ["task_completion"])
            return await api.evaluations.wait(
                run.id, trace_ids=[trace_id], metrics=["task_completion"],
            )
    finally:
        client.shutdown()
```

---
title: "Provider wrappers"
description: "Instrument provider clients while preserving their native calls and results"
---

Wrap the provider client before using it. Calls retain their native arguments, results, exceptions, and streaming behavior. Instrumented calls attach to the active trace or create a standalone trace when needed. Finish or close streams so their trace can be finalized.

Provider packages are optional. Install the provider you use alongside `pandaprobe`; the wrapper does not replace the provider's own API reference. These functions instrument model calls, while the [framework integrations](/tracing/integrations/overview) also capture agent/tool structure.

Provider helpers are available from `pandaprobe.wrappers` and their provider submodules. `wrap_litellm()` is the exception to instance wrapping: it instruments module-level completion functions. Bedrock async support depends on the supplied native client.

## On this page

[wrap_anthropic](#wrap_anthropic), [wrap_bedrock](#wrap_bedrock), [wrap_gemini](#wrap_gemini), [wrap_litellm](#wrap_litellm), [wrap_mistral](#wrap_mistral), [wrap_openai](#wrap_openai).

## Example

Install the provider extra with `pip install "pandaprobe[openai]"` or `uv add "pandaprobe[openai]"`. Set both PandaProbe and OpenAI credentials before making model calls.

```python
from openai import OpenAI
from pandaprobe.wrappers import wrap_openai

model_client = wrap_openai(OpenAI())
# Use model_client.chat.completions.create(...) as usual.
```

## Which reference do I need?

| Task | Reference |
| --- | --- |
| Instrument model or agent execution | SDK tracing, provider wrappers, and framework integrations |
| Look up a method, argument, default, or return type | Python or TypeScript SDK reference |
| Read traces or run evaluations from application code | SDK platform client and resources |
| Add persistent memory and independent rule validation | SDK Reflect reference |
| Call the platform directly or use a server operation without a typed SDK resource | HTTP API reference |

SDK signatures and fields come from the package source and include links to their declarations. HTTP endpoint pages continue to be generated from the core service's `openapi.json`.

For step-by-step integration, use the [Trace quickstart](/tracing/get-started/quickstart), [Evaluate quickstart](/evaluation/get-started/quickstart), or [Reflect quickstart](/reflect/quickstart).

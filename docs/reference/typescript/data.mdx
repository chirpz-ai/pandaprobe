---
title: "Trace data"
description: "Trace, span, score, and message contracts"
---

These are trace-export records, not the platform read models. Construct them for low-level submission through the tracing client, or let contexts and framework integrations construct them.

The wire representation uses snake_case, string enum values, and ISO-8601 timestamps. Serialization omits selected null/empty fields as defined by each record's serializer. Trace and LLM-span input/output use `{"messages": [{"role": "user", "content": "..."}]}`; other span kinds can carry domain-specific values.

Token usage records prompt/completion/total tokens and may include provider-specific numeric usage. Cost is a dictionary of monetary amounts; the SDK does not calculate missing provider prices.

Construct `SpanData`, `TraceData`, and `ScoreData` with their init objects; `toApiDict()` performs wire serialization. The init interfaces shown below describe accepted objects but are not independently exported at the package root.

## On this page

[ScoreData](#scoredata), [ScoreDataInit](#scoredatainit), [ScoreDataType](#scoredatatype), [SpanData](#spandata), [SpanDataInit](#spandatainit), [SpanKind](#spankind), [SpanStatusCode](#spanstatuscode), [TraceData](#tracedata), [TraceDataInit](#tracedatainit), [TraceStatus](#tracestatus).

## Example

```ts
import { SpanData, SpanKind, TraceData } from "pandaprobe";

const now = new Date();
const record = new TraceData({
  name: "lookup", startedAt: now, endedAt: now,
  spans: [new SpanData({ name: "policy", kind: SpanKind.TOOL, startedAt: now, endedAt: now })],
});
const payload = record.toApiDict();
console.log(payload.trace_id);
```
